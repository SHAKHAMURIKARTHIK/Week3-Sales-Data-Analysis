# Week 3: Sales Data Analysis

## Submission files
- `sales_analysis.py` — Python script with the required sample code and full analysis.
- `sales_data.csv` — sample dataset with 100 rows and five columns.
- `analysis_report.md` — generated Markdown report.
- `requirements.txt` — Python dependency list.

## Run the project
1. Keep all files in the same folder.
2. Install pandas: `python -m pip install -r requirements.txt`
3. Run: `python sales_analysis.py`
4. Open `analysis_report.md` to read the report.

The script also creates `cleaned_sales_data.csv` and `product_sales_summary.csv`.
The CSV is a practice dataset and does not represent real business records.
